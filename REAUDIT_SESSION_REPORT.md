### Fixed after the re-certification: user-reported workflow hang (`23057af00`)
Reproduced with the user's workflow on a real Celery worker. (1) A failing step beside parallel branches
made the next superstep's steps write `status` concurrently, and LangGraph raised `InvalidUpdateError`, so
the run died with a framework message instead of pausing on the failing step; run-control state keys now
use a last-write reducer. (2) Credential-free built-ins (web_search, http_request, OCR) were only wired at
startup for tenants that existed then; they are now provisioned on first use for later tenants. (3) The
legacy `helm/agentverse` worker consumed none of the workflow queues. After the fix the user's workflow
runs every step in ~5 s and pauses on its deliberately raising final step, with that error shown.
Note for local testing: the Docker stack on this machine runs images built 6 days ago, and an old local
Celery worker (started 2026-09-23) also consumes the same Redis queues; both run pre-wave-7 code.

## Highest-risk gaps still open

- Marketplace monetization (Fail): nothing marks a purchase as paid, paid templates install for free, the PaymentIntent has no Connect transfer so authors are never paid, and a buyer can be charged for a purchase that never completes (app/api/marketplace_monetization.py). Disable paid templates until this is built.
- Agent-scoped API keys authenticate nothing: /agents/{id}/keys issues them but no auth path resolves them (app/auth/agent_credentials.py), and the credentials page reads fields the API does not return. RS256 agent JWTs do authenticate now.
- RPA tools on the Celery worker: the worker never wires an RPA executor, so agent rpa_* calls on queued goals end as 'Tool not found'; the takeover endpoint says an operator was notified but nothing reads the flag. The browser SSRF hole itself is fixed.
- MFA enforcement is off by default (mfa_enforcement_enabled=False): a tenant that enables MFA gets only a client-side redirect unless the operator turns enforcement on.
- RAFT: RAFTService is built without inference providers, so a fine-tuned model can never serve. Reflexion/canonical memory: nothing calls learn or record_effectiveness, so it stays empty.
- Dynamic orchestration and the strategy registry (Fail): the runtime profile cannot be saved (dataclass passed to json.dumps, no db_session) and much of the readiness/certification catalogue is unused.
- Worker parity: traces of worker-run goals never record their result, worker log lines never reach /observability/logs, and a self-optimizer winner reaches API replicas only after a restart (AgentStore cache).
- Goal dedup is check-then-register (not atomic) with a swallowed register error, so two identical simultaneous submissions both run; eval endpoints still look goals up in one replica's memory.
- SAML and Google SSO verify identity but return an honest 501 because no session is issued; SCIM has only /Users.
- Re-verify grounded knowledge-base chat on the on-prem Qwen cluster once the VPN is up (it passed on NVIDIA after the fix).
