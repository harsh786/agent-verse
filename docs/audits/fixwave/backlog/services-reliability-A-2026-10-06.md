## Notes

- **Behaviour changes on purpose (old tests updated):**
  - The executor breaker tests now mock the async breaker API.
  - The bulkhead tests now use the lease Redis stand-in.
  - The sync `rollback_all` no longer fires and forgets.
  - The `goal_lifecycle` table tests now use real statuses.
  - The bridge tests (`TestSubscribeCeleryGoalEvents`, `start_celery_event_bridge`, the bridge's `_seq` test, and the DB-refresh test that only applied to bridge-fed local queues) were removed. The new per-goal-channel tests replace them.
- **New API surface:** an opt-in `rollback` query parameter on goal cancel and on the tenant and org emergency stops. The new setting is `TENANT_BULKHEAD_WAIT_SECONDS`. `openapi.json` was regenerated; it also picked up earlier drift from main in the agent `timeout_seconds` schema.
- **Rollout:** the tenant bulkhead moves from the `bulkhead:{tenant}` string counter to the `bulkhead_leases:{tenant}` sorted set. Old keys expire within 300 s. The API lifespan no longer starts a `celery_goal_event_bridge` task.
- **Suites run:** `tests/agent` (2,829), `tests/services` + `tests/api` (5,379), `tests/scaling` + `tests/providers` + `tests/reliability` (1,671), plus the named integration files on testcontainers. `ruff check app` and `mypy app` are clean.
- **Not verified:** no live-stack (docker compose) run. The SSE change was checked with fakeredis and a real Redis testcontainer, not with real workers.
