  - Persist a `builder_projects` row: tenant, project, workspace, goal.
  - Have the builder agent write files through a tenant-scoped artifact API keyed by project.

  Option B: remove `/builder/preview` and `/builder/assets`, and keep the builder as "submit a code-generation goal"
  (status now works through `GET /builder/projects/{id}`).

  feature with a real security design behind it.

  `routing_decisions` / `routing_outcomes` in a new migration once they are confirmed empty. The live DB was not
  checked.

  **Recommendation: B.** The live routers are the ones being hardened (MR-6b, RV-02, CORE-33), and this package
  has had no caller since 2026-08.
