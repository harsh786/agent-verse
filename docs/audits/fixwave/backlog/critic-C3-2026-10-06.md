2. **Semantic marketplace search (follows from a10-F246-05).** The 2026-06-28 marketplace spec
   asked for a pgvector search branch. Building it needs three things:
   - an embedder in the worker;
   - fitting the fixed `vector(768)` column to the configured embedding width (as LTM does);

   fall short. Drop the column if it is not wanted.
