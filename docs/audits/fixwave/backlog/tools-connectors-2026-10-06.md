## Notes for the owner

- **a02-F036-02 (email relay):** choose a default posture for relaying from the platform sender:
  (a) an opt-in per-tenant recipient allowlist (domains/addresses), with today's behaviour when it is empty;
  (b) deny by default: only verified recipient domains per tenant (safest, but it breaks current users until they are configured);
  (c) a HITL approval for recipients outside the tenant's own domains;
  (d) per-tenant SMTP (BYO sender), with the platform relay kept only for system mail.
- **New health statuses:** the sweep now writes `ready` and `disabled` for built-ins, beside `healthy`/`degraded`/`unhealthy`/`unreachable`/`invalid_config`. Nothing in the backend or frontend aggregates these strings today.
- **API shape changes:** `/connectors/capabilities/search` and `/missing` now return 503 instead of an empty 200 when discovery cannot run, and they add `complete` and `connector_errors`. No frontend code calls them.
