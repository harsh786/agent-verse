## Formatting

- Two-page, one-column Word layout with standard fonts, real headings, selectable text, and no tables, text boxes, graphics, icons, or multi-column sections that impair ATS parsing.
- Use 10.5-point body text, 1.1 line spacing, and visible spacing before major sections to eliminate the dense, clustered appearance of the first version.
- Present the impact snapshot as a text line, not a table, so it remains ATS-readable.
- Use direct, outcome-oriented action verbs and factual claims only.
