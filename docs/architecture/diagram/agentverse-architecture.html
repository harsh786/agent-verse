How one goal flows

  1. Submit a goal. A person, a CI job, a webhook or another agent sends a natural-language goal. It arrives over HTTPS at the edge gateway.
  2. Authenticate and authorize. Middleware resolves the tenant and caller, applies the tenant's rate limit and checks the route's scope before any router runs.
  3. Pick an agent, admit and persist. An API call, trigger, schedule or org mission starts the goal; an agent is chosen with its autonomy mode. The goal is admitted against the tenant's lease and caps, stored idempotently, and its first event is written.
  4. Queue by plan tier. The goal is enqueued on its plan tier's Celery queue. A worker claims it with a lock and an atomic database claim, so only one runs it.
  5. Plan with context. The runtime screens the goal, recalls memory, retrieves knowledge and asks the planner model for steps.
  6. Execute through the tool gate. Each step runs on the executor model. Every tool call is normalised, screened, checked against policy, permissions and grants, risk-tiered, approved if needed and budgeted.
  7. Act on real systems. The gate dispatches exactly the governed arguments to an MCP connector, the code sandbox or a browser session.
  8. Verify, replan or wait. The verifier model checks the result. Route continues, replans with feedback, parks the goal for a human approval, or finishes.
  9. Stream, record and learn. Every step is an event streamed live to clients. Audit, cost and traces are recorded, and lessons are written to memory for the next goal.

What the three planes do

  1. Control plane. Owns identity, tenancy, agent configuration, policy and grants, approvals, budgets and cost, guardrails and audit. Nothing runs without its decision.
  2. Execution plane. Triggers, schedules, agents and the AI organization start goals. Goals are admitted, queued by plan tier and run through the plan, execute, verify loop; tools are reached only through the governed tool gate. Multi-agent patterns and deterministic workflows run here too.
  3. Intelligence plane. Ingests data into the knowledge base and supplies retrieval, memory across goals, models per role, evaluation, observability and reliability services.
  4. Data & platform. Postgres with row-level security is the system of record; Redis carries queues, locks and live events; telemetry flows to OpenTelemetry, Langfuse, Prometheus and Loki.
