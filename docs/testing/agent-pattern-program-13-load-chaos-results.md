# Program 13 load and chaos evidence

This file is generated as the release evidence index. Static harness validation is automated
by `tests/reliability/test_coordination_chaos_contracts.py`. Live k6 and Chaos Mesh results
must be attached here with UTC timestamps, image and adapter digests, cluster identity,
threshold output, accepted-work reconciliation, sequence continuity, and the rollback result.

No live result is recorded until the credentialed test namespace has run. Missing or stale
evidence forces a `hold` decision; it can never be interpreted as certification.
